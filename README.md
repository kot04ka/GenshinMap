# GenshinMap — интерактивная карта-оверлей для Genshin Impact

Десктоп-приложение для Windows: **настоящая карта Тейвата** (тайлы HoYoLAB, все
регионы вплоть до Нод-Края и Снежной) поверх игры, определение позиции игрока
по мини-карте и **автоматическая отметка собранного**.

> Только анализ экрана: ничего не читается из памяти игры и ничего не
> нажимается в игре. Экран читается только когда активно окно Genshin.

## Скачать
Готовая версия — в [Releases](../../releases/latest): скачать `GenshinMap.zip`,
распаковать папку целиком, запустить `GenshinMap.exe`. Игра — в **оконном или
безрамочном** режиме. Дальше приложение обновляется само.

## Что умеет
- **Карта:** Тейват, Энканомия, Разлом, Древняя Священная гора; регионы-чипы,
  706 категорий с поиском, прогресс «собрано/всего», равномерное прореживание.
- **Позиция игрока** по мини-карте (защита от ложных прыжков, честное «позиция
  потеряна» в подземельях), мини-оверлей поверх игры со следованием за игроком.
- **Авто-отметка по факту сбора:**
  - сундук — нажал F у сундука, и в списке «Получено» появился «Опыт приключений»;
  - окулус / кристалл / агат… — его название появилось в «Получено» (Windows OCR);
  - телепорт / статуя — подошёл вплотную.
- **Свои точки** — сундуки, которых нет на HoYoLAB (ставятся сами или правым
  кликом по карте).
- **🧹 Зачистка региона** — что осталось по типам, ближайшее несобранное,
  🗺 маршрут по сундукам, фильтры, 💎 счётчик примогемов.
- **Карточка точки** — подсказка и фото HoYoLAB + советы игроков
  (genshin-impact-map.appsample.com).
- **Прогресс** — в файл / из файла, импорт с HoYoLAB и appsample, отдельный
  прогресс для каждого аккаунта (UID читается с экрана).
- **Автообновление** программы (GitHub Releases) и данных карты (HoYoLAB).

Горячие клавиши (меняются в ⚙): Ctrl+Alt+O — мини-оверлей, Ctrl+Alt+H —
скрыть/показать, Ctrl+Alt+M — отметить ближайшее, Ctrl+Alt+B — закладка.

## Запуск из исходников
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python tools\fetch_map_data.py      # данные карт HoYoLAB (точки, категории, иконки)
python tools\fetch_appsample.py     # соответствие точек для советов игроков
python main.py
```

## Сборка и выпуск версии
```powershell
python tools\build_exe.py                        # build\release\GenshinMap.zip
python tools\release.py 1.0.1 "что нового"       # версия -> сборка -> коммит -> релиз
```
В сборку идут только общие данные; прогресс, настройки и записи пользователя — нет.
После релиза у всех копий появляется кнопка «⬇ Обновить».

## Устройство
```
main.py                            точка входа (запрос прав администратора — как у игры)
tools/                             загрузка данных, сборка exe и Rust-модуля, выпуск версии,
                                   ui_snapshot.py — проверка страницы карты без игры
native/                            Rust-модуль (PyO3): быстрый A* для пути по местности
src/genshinmap/
  backend/                         логика без окон
    core/                          пути, версия, настройки и прогресс, языки интерфейса
    maps/                          данные карты, точки, регионы, свои точки, путь (A*),
                                   задания, карточка точки, анимация «как пройти»
    game/                          авто-отметка, примогемы, процесс игры, файл прогресса
    services/                      автообновление, данные HoYoLAB, локальный http-сервер
    vision/                        позиция по мини-карте, OCR, подсказки, запись отладки
  frontend/                        всё, что видит пользователь
    theme.py                       цвета и размеры (общие для окон и карты)
    qt/                            окно, мини-оверлей, HUD, настройки, калибровка, иконки
    web/                           карта Leaflet: map.html + css/ + js/ + словарь en
```
Frontend и backend общаются только через мост `frontend/qt/bridge.py` (QWebChannel).

Проверки: `python -m ruff check .` и `python -m pytest` (tests/test_ui.py открывает
карту в настоящем движке: нет ошибок JS, на английском не осталось русского текста).
Rust-модуль необязателен: `python tools/build_native.py` (без него A* на Python).

## Данные
Точки и категории — из публичного API HoYoLAB; советы игроков — с
genshin-impact-map.appsample.com. Данные принадлежат их владельцам и
используются для личного трекинга прогресса. Эндпоинты неофициальные и могут
меняться.
