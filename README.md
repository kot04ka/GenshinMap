# Genshin Interactive Map (оверлей)

Десктоп-оверлей для Windows: **настоящая интерактивная карта Тейвата** (реальные
тайлы игры) со всеми коллекционными предметами — сундуки, окулюсы, знаки/сили,
сокровищницы и т.д. Приложение определяет, запущена ли игра, и позволяет
отмечать собранное. Автоматическое распознавание сбора через анализ экрана —
в разработке (Этап 2/3).

> ⚠️ Только анализ пикселей экрана. Никакого чтения памяти игры — это нарушает
> правила mihoyo и грозит баном аккаунта.

## Стек
- **PyQt6** — окно-оверлей поверх игры
- **Leaflet.js** (в QWebEngineView) — интерактивная карта с тайлами и маркерами
- **psutil** — определение процесса `GenshinImpact.exe` / `YuanShen.exe`
- **mss + OpenCV** — захват экрана и распознавание (Этап 2)

## Данные карты
Тайлы, категории (706 шт.) и точки (~88 000 шт.) берутся из публичного API
HoYoLAB (`tools/fetch_map_data.py`). Данные — собственность miHoYo, используются
для личного трекинга прогресса. Эндпоинты неофициальные и могут меняться.

## Установка
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Первый запуск
```powershell
# 1) скачать ВСЕ карты (Тейват, Энканомия, Разлом, Древняя Священная гора):

#    (или только нужные: python tools\fetch_map_data.py 2 7)

# 2) запустить приложение

```

## Мультикарта
Поддерживаются все карты HoYoLAB (`data/maps/index.json`): Тейват (map_id=2),
Энканомия (7), Разлом (9), Древняя Священная гора (36) и т.д. Переключение —
выпадающим списком «Карта» в правой панели. Каждая карта хранится в
`data/maps/<id>/` и `assets/maps/<id>/`.

Все карты грузятся в формате `detail_v2`: тайлы подтягиваются с CDN HoYoLAB
по зумам (актуальная карта со всеми регионами — Натлан, Нод-Край, Снежная).
Карта показывается по реальным границам контента, без пустых полей.

## Как пользоваться
- Сверху над картой — **регионы** (Мондштадт, Ли Юэ, … Снежная). Клик —
  перелёт к региону и фильтр: маркеры и счётчики только этого региона.
  «Весь мир» (или ⌂ справа) — вся карта. На отдалении регионы подписаны прямо на
  карте с прогрессом «собрано N из M» по включённым слоям.
- Слева — категории по группам с поиском. Галочка у группы включает/выключает
  всю группу. У категорий — «собрано/всего» и полоска прогресса.
- Включённые слои видны чипами над списком (× — выключить). «Скрыть собранные»
  убирает с карты уже отмеченные точки, «Снять все слои» — выключает всё.
- Клик по маркеру = отметить/снять «собрано» (`data/progress.json`).
- Если точек в кадре больше лимита — они прореживаются **равномерно по всей
  области** (а не «первые N»), внизу подсказка «приблизь, чтобы увидеть все».

## Позиция игрока (Этап 3)
Кнопка **📍 Отслеживать** в правой панели. Приложение матчит мини-карту против
референса карты (собирается из v2-тайлов один раз, ~40 с для Тейвата, кеш
`assets/maps/<id>/ref_*.png`) и показывает игрока жёлтой точкой. Кнопки справа
на карте: ⌖ — показать игрока, ◎ — карта следует за игроком.

- Глобальный поиск (после телепорта/загрузки) — 1–3 с, обычный трекинг — мс.
- Масштаб мини-карты подбирается **сам** при первом успешном поиске (~15 с) и
  сохраняется в `data/settings.json` (`minimap_scale`).
- В однородных местах (пустыня, море, снег) позиция помечается «неуверенной» и
  не используется для авто-отметки — лучше промолчать, чем отметить не то.
- Мини-карта Genshin всегда ориентирована на север — углы перебирать не нужно.

**Калибровка (🎯)** — один раз: «Снимок через 3 с» (окно спрячется,
переключись в игру) или открыть свой скриншот, обвести мышью круг мини-карты
(жёлтая рамка) и область, где всплывают подобранные предметы (голубая).
«Проверить позицию» сразу покажет найденную точку на карте.

## Авто-отметка сбора
Включена всегда, отмечает по факту сбора (не «пробежал мимо»), независимо от слоёв:
- **сундук** — нажал F у сундука, и в списке «Получено» (слева) появились новые
  строки сундука: «Опыт приключений» или предметы с Морой (Windows OCR);
- **окулус / кристалл / агат…** — в «Получено» появилось его название рядом с точкой;
- **телепорт / статуя** — подошёл вплотную;
- «вероятно собрано» (❔) — по подсказке «F Открыть», если снят её эталон в Калибровке.
- Журнал (двойной клик — показать точку, «↶ Отменить»), диагностика —
  `debug/automark.log`. Экран читается и пишется ТОЛЬКО когда активна игра.
- Окно карты не должно закрывать мини-карту и список «Получено» (будет ⚠).

## Маршрут и HUD (тест)
Кнопка 🗺 — маршрут по несобранным сундукам региона игрока (ближайший сосед +
2-opt). Поверх игры (прозрачное окно, клики проходят насквозь) — стрелка у края
мини-карты, расстояние, подсказка с фото рядом с целью, звук. `hud_enabled` в
settings.json. Автобег персонажа намеренно НЕ делается (правила игры, бан).

## Советы игроков и примогемы
Клик по маркеру — карточка: подсказка и фото HoYoLAB + советы игроков с
genshin-impact-map.appsample.com (соответствие точек: `tools/fetch_appsample.py`).
Панель «💎 Примогемы» — оценка по типам собранных сундуков (сессия/регион/всего).

## Сборка exe для другого человека
```powershell
python tools/build_exe.py      # dist/GenshinMap/ и dist/GenshinMap.zip
```
В сборку идут только общие данные; личные прогресс/настройки/записи — нет.
Запуск просит права администратора (как у Genshin) — отключается в ⚙.

## Горячие клавиши (глобальные)
- **Ctrl+Alt+M** — отметить ближайшую к игроку точку (категория последнего
  подбора, иначе все включённые слои).
- **Ctrl+Alt+O** — мини-оверлей поверх игры вкл/выкл.
- **Ctrl+Alt+H** — быстро скрыть/показать окно (удобно при альт-табе в игру).

В мини-режиме: перетаскивай окно мышью; меняй размер за уголок (правый-низ);
кнопка **⤢** справа-сверху — вернуться в обычный вид. Масштаб карты — колёсиком
мыши или кнопками +/− (правый верх карты).

## Производительность
Точек очень много (~88k). Маркеры рендерятся только для видимой области
(viewport culling) с лимитом `max_markers` (⚙ Настройки); сверх лимита —
равномерное прореживание по сетке экрана. Тайлы грузит Leaflet сам по зуму.

## Сброс прогресса
Кнопка «🗑 Сброс» (нажать дважды) в правой панели снимает все отметки «собрано»
(и на карте, и в `data/progress.json`). При запуске ничего не отмечено по
умолчанию — категории показываются только когда ты сам ставишь галочку.

## Структура
```
main.py                            точка входа
tools/fetch_map_data.py            категории/точки/геометрия v2 из API HoYoLAB
src/genshinmap/
  regions.py                       названия регионов (area_id) и их границы
  mapindex.py                      поиск ближайшей несобранной точки
  storage.py                       прогресс, состояние UI, настройки
  detector/process_watcher.py      определение запуска Genshin
  overlay/window.py                главное окно + сборка бандла карты
  overlay/calibration_dialog.py    калибровка мини-карты и плашки подбора
  overlay/settings_dialog.py       настройки
  overlay/bridge.py                мост Python <-> JS (QWebChannel)
  web/map.html                     карта Leaflet (тайлы v2, регионы, категории)
  web/mapdata_<id>.js              сгенерированный бандл данных карты (авто)
  vision/position_tracker.py       позиция по мини-карте (референс из тайлов)
  vision/position_service.py       фоновое отслеживание позиции
  vision/collector_detector.py     распознавание плашки подбора (эталоны)
  vision/detection_service.py      фоновый сервис распознавания
data/maps/<id>/                    meta / labels / points
assets/maps/<id>/                  иконки категорий + референс для позиции
```

## Этапы
1. ✅ Реальная карта (v2, все регионы) + регионы + категории + прогресс + сохранение
2. ✅ Пайплайн распознавания подбора. Нужно наполнить эталонами своих скриншотов.
3. ✅ Позиция игрока по мини-карте (автокалибровка масштаба, трекинг) +
   авто-отметка с отменой + калибровка мышью. Проверено на синтетике — нужна
   проверка в живой игре.
